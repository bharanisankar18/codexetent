Codextent Settings

Theme, where your programs run, and how outputs are compared.
Welcome! Codextent works out of the box with the free public Judge0 server. Click Test connection to check it, then open a C, C++, Java, Python or MySQL example on a supported learning site and click the <⚡> button under the code.

Appearance

Used by My Learning Hub, the popup, Settings, and the bar under code examples. Changes apply instantly.

Code runner (Judge0)

Stored only in this browser (chrome.storage.local). It is used by the extension's background worker and is never shared with the websites you visit.

Judge0 CE defaults: C 50, C++ 54, Java 62, Python 71, SQL 82. MySQL examples run on Judge0's SQL engine (SQLite) with MySQL-only options removed.

Comparing outputs

Always applied: Windows line endings count as normal newlines, and whitespace at the very end of the output is ignored. MySQL results are compared cell by cell: separate cells with |, tabs or spaces, with or without the header row.
