Optional language logos for the Codextent dashboard.

Put SVG files here named exactly:
  c.svg   cpp.svg   java.svg   python.svg

If a file exists, the dashboard shows it in the language switcher and on attempt cards.
If not, a monochrome lettermark (C, C++, J, Py) is shown.
